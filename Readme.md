# test

## 1. Install the dependency for the monorepo:

```
npm install
```

## 2. Start the services in Docker:

```
docker compose up --build
```

## Local Development

### Start client (Vite):

```
npm run start:client
```

### Start server (NestJS):

```
npm run start:server
```

## Available resources:

[Client (Vite)](http://localhost:3000): http://localhost:3000
[Server (NestJS API)](http://localhost:8000): http://localhost:8000
